# Week 10: GeoPandas Exploration, Joins and Maps

## Overview

This week's work explored how GeoPandas can be used to read, inspect, filter, manipulate, join and visualise geospatial datasets using Python.

The practical work used the Eastern Cape renewable energy project dataset from my previous GeoDev Lab work.

## Data Used

The independent challenge used the Eastern Cape renewable energy GeoPackage:

`data/processed/eastern_cape_renewable_energy.gpkg`

The GeoPackage contains the following layers:

- `renewable_projects`
- `eastern_cape_municipalities`
- `eastern_cape_grid`

The renewable energy projects layer contains 254 features, while the municipality layer contains 52 features.

The dataset uses CRS EPSG:9221.

## Findings

The exploration identified 254 renewable energy project records.

The technology distribution was:

- Wind: 167 projects
- Solar PV: 78 projects
- Biomass and biofuels: 4 projects
- Petroleum: 3 projects
- Wind and Solar PV: 2 projects

Geometry inspection showed that all 254 project features were MultiPolygon geometries. A validity check identified 246 valid geometries and 8 invalid geometries.

The spatial join linked renewable energy project geometries with municipal boundaries. The resulting join contained 308 records because some project geometries intersected more than one municipality.

## Challenges and Limitations

- The `MEGAWATT` attribute was stored as text and needed conversion to numeric values before numerical filtering and sorting.
- Eight project geometries were identified as invalid during geometry inspection.
- Some project geometries intersected multiple municipal boundaries, increasing the number of records in the spatial join.
- The available project and municipality layers did not contain a population attribute, so the spatial join did not represent a population analysis.

## Conclusion

This week's exercises improved my understanding of working with geospatial data in Python. I gained practical experience exploring GeoPackages, inspecting attribute and geometry properties, filtering records, converting geometries, performing spatial joins and producing maps using GeoPandas.
